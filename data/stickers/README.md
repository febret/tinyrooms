These test stickers are generated using the SBURB session simulator
(http://www.farragofiction.com/SBURBSim/oc_generator.html).

They are the preset choices offered by the Sticker Designer activity. The
"Design your own" mode uses [original SVG parts](../../client/activities/sticker-designer/parts/)
and stores rendered results per account under `TRSERVER_CUSTOM_STICKERS_PATH`
(`.local/stickers` by default), not here.
